# Netflix (网飞) 平台使用指南

CoWatcher 专为 Netflix 自研的 Kadmium 视频播放引擎进行了深度原生集成。

---

## 核心特性

- **双语同屏显示**：顶部显示原声字幕（如英语/日语），底部显示母语 AI 翻译字幕（如中文），或者上下互换。
- **专有播放器时钟同步**：自动对齐 Netflix 的分段播放时间戳，拖动进度条（Seek）时无缝瞬间跳转，零卡顿。
- **原生字幕智能控制**：开启 AI 双语字幕后，自动隐藏 Netflix 原生单语白字字幕，防止重叠。

---

## 快捷操作与技巧

1. **一键切换**：在播放页面随时按下 **`Alt + T`** 即可开启或关闭双语字幕。
2. **字幕上下对调**：
   - 如果你想把原声字幕放在下方，译文放在上方，打开 CoWatcher 弹窗面板，勾选 **Swap Subtitle Order** 即可。
3. **生词即点即查**：
   - 鼠标悬停在原文字幕中的陌生单词上，即可一键查看发音、释义并收藏进个人生词本。
